# C# Console Calculator

A simple, robust console-based calculator built as part of the Backend .NET Track. 

## Description
This application allows users to perform basic arithmetic operations (addition, subtraction, multiplication, and division). It features input validation to prevent crashes from non-numeric characters and includes strict handling for division-by-zero errors. Users can perform multiple calculations consecutively without restarting the app.

## Technologies Used
* **Language:** C# 
* **Framework:** .NET Console Application
